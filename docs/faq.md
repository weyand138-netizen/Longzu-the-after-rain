# 常见问题

[返回首页](../README.md) · [全部版本](versions.md) · [反馈](../SUPPORT.md)

## 应该下载哪个文件？

使用首页明确标出的推荐 Windows 游戏包，并留意它是正式版还是测试版。正式版尚未发布时，所有公开包仍按测试／候选版对待。`Source code` ZIP/TAR 是源码归档，不是独立游戏包。

## 需要安装 Python 或 Ren'Py 吗？

Windows 独立游戏包包含运行环境，无需另行安装。下载后完整解压，再启动对应程序。当前公开 RC.1 使用 `雨停之后.exe`，早期公开测试版使用 `After rain.exe`，以对应版本说明为准。

## 支持哪些平台和语言？

项目面向 Windows 10 / 11 x86-64，游戏语言为简体中文。目前没有公开发布的 macOS、Linux、Android、iOS 版本，也没有角色配音或英文游戏翻译。英文首页用于提供项目信息。

当前候选的实际启动核验在 Windows 11 完成，最低硬件配置尚未独立确认。不把这一记录扩大为所有 Windows 设备的兼容保证。

## 如何升级，旧存档能继续使用吗？

先保留旧目录和存档，再将新版完整解压到新目录。不要用覆盖安装的方式混入旧脚本和素材。

当前候选保留既有存档格式和目录标识，并提供旧存档导入确认。已对历史存档副本进行核验，但不承诺任意时期或修改过的存档都兼容。若读取出现问题，先保留原数据，通过邮箱提供来源版本、报错和操作步骤，不必先删除存档。

## 可以调整字号、音量或阅读方式吗？

设置页提供字体缩放、高对比、减少动态效果和音量设置；游戏包含回退、快进与自动阅读。中文自朗读还依赖系统语音环境，其实际发音与操作体验以真实设备为准。

## 游戏是否需要联网？

游戏可离线游玩。向作者反馈问题需要你自行发送邮件或提交 GitHub Issue，不会因为点 Star 或发送反馈而解锁游戏内容。

## 为什么不同路线的结局不同？

结局由此前的选择与准备决定。建议根据正文和可操作选项理解因果；反馈某条路线的问题时，请记录关键选择。公开讨论结局请标注剧透。

## 启动器被安全软件拦截怎么办？

先核对下载来源、版本和 Release 中的 SHA-256，并记录检测名称与被拦截文件。请通过邮箱反馈，不以关闭防护作为默认解决方式。旧自定义启动器曾出现被隔离的问题，新候选已更换启动器并做本机扫描；这不是对所有设备或未来检测结果的保证。

## 可以赞助或打赏吗？

本项目暂不接受赞助或打赏，也没有付费内容。欢迎点 Star、分享仓库或 Release 链接，或提供具体反馈。

## 可以使用仓库里的图片、音乐或代码吗？

公开查看不代表可以自由复用。请遵守仓库 LICENSE 和文件自身声明；第三方内容遵守对应条款。需要进一步说明时，请联系作者。
