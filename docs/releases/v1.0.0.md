《雨停之后》是一部免费、非商业的《龙族》非官方同人视觉小说。玩家以路明非的有限视角，陪绘梨衣度过七天，在观察、询问、准备与承担中作出选择，并走向六种不同的结局。

## 游戏内容概述

故事从雨中的站台开始。玩家以路明非的有限视角，陪绘梨衣走过七天：短暂的日常、一次次询问与回应，以及逐渐需要面对的真相和去向，共同组成这段旅程。

你需要留意她写下的话、递来的物件，以及每次沉默中的反应，决定何时解释、何时等待，又该怎样为接下来的路做准备。此前的选择会在后续情节中留下回响，影响彼此的理解和最终走向。

游戏以文字阅读、场景演出和分支选择推进，包含六个确定性结局及各自尾声。不同结局呈现不同选择积累后的结果，而非随机抽取的结局。

## 内容与阅读功能

- 序章至 Day 7 的七日故事，六个确定性结局与各自尾声。
- 18 张结局事件 CG，以及章节场景、角色动作和道具演出。
- 背景音乐、环境声与剧情音效。
- 存档、读档、回退、快进、自动阅读和字体等设置。

游戏语言为简体中文，目前没有角色配音。

下载本 Release 的 Windows 游戏 ZIP，完整解压后运行 **`雨停之后.exe`**。不需要安装 Python 或 Ren'Py。请勿把 GitHub 的 Source code 归档当作独立游戏包。
