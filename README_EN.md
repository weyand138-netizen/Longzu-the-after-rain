# After the Rain

[简体中文](README.md)

An unofficial *Dragon Raja* fan visual novel. From Lu Mingfei's limited point of view, the player accompanies Erii through seven days and changes the course of the story through understanding, respect, and preparation.

Built with Ren'Py 8.5.3, the current version includes a playable prologue through Day 7, six deterministic endings, original visual and audio assets, full save support, and accessibility options.

> This is a free, non-commercial, unofficial fan work. It is not affiliated with or endorsed by the original author, publisher, or any official rights holder. It does not reproduce passages from the original novels or use official illustrations, music, logos, or game assets.

## Current Status

The project is currently in development and includes:

- A Ren'Py 8.5.3 project;
- Five hidden causal axes and deterministic ending resolution;
- A complete seven-day main story, from the prologue *Escaping the Rain* through Day 7;
- Six endings determined by the player's established choices and state;
- Eleven local achievements, with separate collections for endings and chapter memories;
- Original music, ambience, interaction sounds, backgrounds, characters, and props;
- Save, load, rollback, text-speed, self-voicing, and accessibility settings.

## Running Locally

1. Download and extract the Ren'Py 8.5.3 SDK.
2. In the Ren'Py Launcher, set the projects directory to the parent folder of this repository and select `雨停之后`.
3. Choose **Launch Project**. The repository does not include the Ren'Py SDK, caches, or save data.

You can also run the project from the Ren'Py SDK directory. Replace `<project-directory>` with the location of this repository:

```powershell
.\lib\py3-windows-x86_64\python.exe renpy.py <project-directory> run
```
